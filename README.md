# Алгоритм сортировки кучей (Heap Sort)

Реализация алгоритма сортировки кучей на Python.

## Описание

Heap Sort - это алгоритм сортировки, использующий структуру данных "куча" (heap).
- **Время работы**: O(n log n) в любом случае
- **Пространственная сложность**: O(1) (сортировка in-place)

## Структура проекта

- `main.py` - основная реализация алгоритма сортировки кучей
- `test_sort.py` - unit-тесты для модуля сортировки

## Использование

```python
from main import heap_sort

arr = [12, 11, 13, 5, 6, 7]
sorted_arr = heap_sort(arr)
print(sorted_arr)  # [5, 6, 7, 11, 12, 13]
```

## Запуск тестов

```bash
# Через unittest модуль
python3 -m unittest test_sort.py -v

# Или напрямую
python3 test_sort.py
```

## Запуск основного приложения
