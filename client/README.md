# Lab 3: Массивы и сортировка — Клиентская часть

Клиентское приложение для работы с массивами и их сортировкой. Реализовано на React с использованием Vite.

## Описание

Веб-интерфейс для:
- Авторизации и регистрации пользователей
- Ввода массивов чисел (вручную или генерация случайных)
- Сортировки массивов алгоритмом Shell
- Сохранения результатов в базе данных
- Просмотра истории сохранённых массивов

## Технологии

- **React 19** — библиотека для создания пользовательских интерфейсов
- **Vite 7** — инструмент сборки и разработки
- **ESLint** — линтер для проверки кода

## Установка

```bash
npm install
```

## Запуск

### Режим разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

### Предпросмотр продакшен-сборки

```bash
npm run preview
```

## Структура проекта

```
client/
├── src/
│   ├── App.jsx          # Главный компонент приложения
│   ├── App.css          # Стили приложения
│   ├── api.js           # API клиент для взаимодействия с сервером
│   ├── main.jsx         # Точка входа
│   └── index.css        # Глобальные стили
├── public/              # Статические файлы
└── dist/                # Собранные файлы (генерируется при сборке)
```

## Скрипты

- `npm run dev` — запуск сервера разработки с hot reload
- `npm run build` — сборка проекта для продакшена
- `npm run lint` — проверка кода линтером
- `npm run preview` — предпросмотр продакшен-сборки

## Особенности

- Авторизация через JWT токены
- Адаптивный дизайн
- Валидация форм
- Уведомления о статусе операций
- История сохранённых массивов с возможностью удаления
